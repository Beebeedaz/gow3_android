The native display and X11 input bridges from the fexdroid project
(https://github.com/cobrabm12/fexdroid) were reused unmodified by earlier builds. They
belonged to the retired glibc/proot runtime: the X11 display bridge is replaced by
libgow3present, and the XTEST input bridge could never work under Bionic, which has no X
server. Neither binary is part of this build any more.

Vulkan driver: not bundled in this APK at all. The game loads whichever
adrenotools-style driver pack the player installs under files/drivers/<name>
(launcher DriverManager download or manual install; the shipped default is the
phone's own driver, gow3.ini: gpu_driver). No Mesa/Turnip code is built or
distributed with this app.

Frame generation: not part of this app. The Bionic runtime loads no LSFG layer
and the launcher's FRAME GENERATION entry is disabled; no lsfg-vk component is
built or shipped. Lossless Scaling and its Lossless.dll are not included and
are never redistributed with this app: the player supplies their own copy,
either by importing the file on the launcher Home page (FRAME GENERATION,
IMPORT .DLL) or by signing in to Steam below. The app only stores it in its
own private folder.

Steam sign-in (downloads Lossless.dll from the player's own Lossless Scaling):
JavaSteam 1.8.0 (MIT, https://github.com/Longi94/JavaSteam), with Kotlin and
kotlinx.coroutines/io/serialization (Apache-2.0, JetBrains), Ktor (Apache-2.0,
JetBrains), OkHttp and Okio (Apache-2.0, Square), Protocol Buffers for Java
(BSD-3-Clause, Google), Apache Commons Lang 3 (Apache-2.0), SLF4J API (MIT),
JetBrains annotations (Apache-2.0), XZ for Java (0BSD, Lasse Collin) and
zstd-jni (BSD-2-Clause, Luben Karavelov; bundles Zstandard, BSD). The QR code
is drawn with ZXing core 3.5.4 (Apache-2.0). Menu icons: Material Design icons
(Apache-2.0, Google).

FSR 3.1: AMD FidelityFX (MIT) through
FireBurn/FSR-Vulkan.
